# Задание для Claude Design: веб-интерфейс «GP → MIDI» как пошаговый мастер

Как пользоваться: подключите в Claude Design репозиторий
`github.com/maximgrigorov/gpmidi` и вставьте раздел «Промпт» целиком.
Подробный разбор текущего интерфейса и целевой поток — в
[`docs/UI_WIZARD_PLAN.md`](UI_WIZARD_PLAN.md).

---

## Промпт

Спроектируй новую версию веб-интерфейса конвертера Guitar Pro → MIDI. Главная
задача — **логика и порядок**: сейчас всё на одном экране. Нужен пошаговый
мастер, в котором человек не теряется.

### Кто пользователь

Гитарист. Он пишет партии в Guitar Pro на слух и по транскрипциям, потом
загружает файл сюда и получает MIDI для Logic Pro с инструментами Shreddage:
Hydra — гитара, Darkwall — бас, Shreddage Drums. Цель — не «сыграть ноты», а
**оживить** их: живой тайминг барабанщика, ритм-секция вместе с бочкой,
штрих, движение руки. Решения он принимает на слух, поэтому ему важно быстро
собрать два варианта и сравнить.

### Что прочитать в репозитории

- `templates/index.html` — текущая страница целиком (Jinja + ванильный JS), в
  том числе piano-roll и плеер предпрослушки.
- `static/style.css` — текущие токены: светлая тема, Inter и JetBrains Mono,
  синий акцент `hsl(221 78% 52%)`, радиусы 6–10 px.
- `app.py` — `TRACK_EFFECTS` (какие опции доступны какому типу дорожки),
  `default_track_effects` (что включено по умолчанию), `parse_track_options`
  (имена полей формы), `process_job`.
- `docs/UI_WIZARD_PLAN.md` — разбор проблем, целевой поток, ограничения, этапы.
- `AGENTS.md` — что каждая опция делает с музыкой. Смысл опций не
  переосмысливать.

### Что не так сейчас

- **Шаги разорваны.** «Шаг 1» (загрузка) в боковой панели, «Шаг 2» — в
  основной области, у результата номера шага нет.
- **Переключатели сплошной стеной.** До кнопки «Обработать» — 38 чекбоксов
  эффектов, по 12 на каждой гитарной дорожке. Подписи вперемешку
  по-английски и по-русски, зависимости выражены текстом «(needs humanize)».
- **Нет пути назад.** После обработки опцию не поменять: файл нужно загрузить
  заново, и сравнить два варианта невозможно.
- **Скрытая ловушка.** «Вместе с барабанами» при неоживлённых барабанах
  привязывает к ровной сетке, и интерфейс об этом молчит.
- **Скачивание разбросано** по шапке и 7-колоночной таблице. Таблица
  прокручивается вбок уже на 1440 px, до 16 плашек режимов, надпись
  «Enriched ещё не собран» висит, даже когда его не заказывали.
- **Телефон:** содержимое начинается ниже первой тысячи пикселей, над ним вся
  боковая панель.

### Что спроектировать

Мастер из пяти шагов со степпером, шаг хранится в URL:

1. **Файл.**
   - Зона перетаскивания `.gp / .gp5 / .gp4 / .gp3 / .gpx` до 128 МБ.
   - Недавние сессии.
   - Разбор только читает файл, после него — автоматический переход дальше.
2. **Дорожки.**
   - Выбор дорожек, распознанный тип (Hydra / Darkwall / Shreddage Drums /
     без маппинга).
   - Роль: Барабаны / Ритм-секция / Соло / Прочее. Роль определяется
     автоматически, для гитары и баса её можно сменить.
3. **Звучание** — главный шаг.
   - Опции сгруппированы по ролям. Зависимости выражены вложенностью, а не
     серыми пунктами с оговорками.
   - Свёрнутый блок «Точность нот».
   - Раскрывающаяся таблица «по дорожкам» для исключений.
   - Seed.
4. **Дополнительно** (необязательно): играбельные табы; план выразительности
   (эксперимент, виден только если на сервере настроен OpenAI).
5. **Результат:**
   - одна главная кнопка «Скачать всё для Logic (`_ALL.mid`)», рядом ZIP;
   - дорожки карточками: предпрослушка, MIDI, Double, табы;
   - «Что применено» человеческим языком;
   - чек-лист «Настройка DAW»;
   - «Изменить звучание и пересобрать» — каждая сборка сохраняется версией
     (v1, v2…) для сравнения на слух.

Состояния, которые нужно показать:
- пустое;
- ошибка разбора и слишком большой файл;
- ни одной дорожки не выбрано;
- предупреждение «вместе с барабанами без оживления барабанов»;
- идёт сборка (секунды; с табами и OpenAI — дольше);
- ошибка сборки;
- две версии в результате;
- старая сессия без версий.

Общая оболочка: навигация «GP → MIDI / Audio → MIDI / Проекты» и история
сессий (выдвижная панель или отдельная страница — предложи).

### Жёсткие ограничения

- Музыкальная логика не меняется. Интерфейс только собирает те же поля формы:
  `track_indices`, `track_<N>_<ключ>`, `seed`, `playable_tabs`,
  `prepare_arrangement_context`, `openai_arrangement_draft`,
  `arrangement_prompt`.
- Не выдумывать новых опций, не объединять две опции в одну и не менять
  дефолты:
  - скрытые 32-е включены на всех тональных дорожках;
  - авторские сдвиги GP8 — только на соло;
  - всё остальное выключено.
- Реализация — Flask + Jinja + ванильный JS, без SPA-фреймворка и сборки.
  Проектируй то, что реально сверстать серверными шаблонами.
- Светлая тема. Визуальный стиль можно освежить, но спокойно и сдержанно;
  текущие токены — отправная точка, не догма.
- Язык интерфейса — русский, по-музыкальному; технический ключ опции — во
  всплывающей подсказке (tooltip).
- Ширина 1440 px и 375–390 px без горизонтальной прокрутки. Цели нажатия от
  44 px, контраст текста от 4.5:1, настоящие `button` / `input` / `label`.

### Все опции (ничего не добавлять и не терять)

| Ключ формы | Смысл | Дорожки | По умолчанию | Зависит от |
|---|---|---|---|---|
| `humanize` | оживление: velocity и микротайминг (на гитаре ещё штрих аккорда) | барабаны, гитара, бас | выкл | — |
| `ghost_notes` | гост-ноты малого — **добавляет ноты** в партию | барабаны | выкл | `humanize` |
| `lock_to_drums` | бас и гитары берут тайминг бочки и малого | гитара, бас | выкл | `humanize`; имеет смысл, только если оживлены барабаны |
| `double_track` | второй дубль ритм-гитары L/R, отдельный файл «(double)» | гитара | выкл | `humanize` |
| `palm_mute_motion` | глубина глушения плавно «гуляет», как рука | гитара | выкл | `humanize`; в пресете нужен Vel → Tightness |
| `fret_hand_cost` | задержка атаки при переносе левой руки (9–16 мс от 4 ладов) | гитара | выкл | `humanize` |
| `humanize_timing_over_gp_offsets` | тайминг оживления поверх авторских сдвигов GP8 | гитара, бас | выкл | `humanize` и `preserve_gp_played_offsets` |
| `pick_direction` | направление медиатора (кейсвитчи Hydra C7/C#7) | гитара | выкл | — ; в пресете проверить Picking Mode |
| `auto_sustain_vibrato` | вибрато (глубина CC1) на длинных одиночных нотах соло | гитара (соло/лид) | выкл | — |
| `fret_noise_on_hand_shift` | шорох струн при переносе позиции | гитара, бас | выкл | — |
| `expand_gp_hidden_32nds` | ноты, сыгранные подряд внутри бита, разносятся на 32-е | гитара, бас, прочие | **вкл** | — |
| `preserve_gp_played_offsets` | сохранять авторские сдвиги атак GP8 | гитара, бас | **вкл на соло** | — |
| `keep_gp_played_overlaps` | оставлять перекрытия от сдвигов (Hydra сыграет легато) | гитара, бас | выкл | `preserve_gp_played_offsets` |

На песню: `seed` (0–9999, по умолчанию 7), `playable_tabs` (ASCII/PDF-табы и
GP с новой аппликатурой для гитар и баса), план выразительности:
`prepare_arrangement_context` → `openai_arrangement_draft` → `arrangement_prompt`.

Что есть в результате сейчас (сохранить, но переупорядочить):
- общий `_ALL.mid` и MIDI по дорожкам, файл «(double)»;
- артефакты табов и печать PDF на A4 (если настроен принтер);
- GP с новой аппликатурой;
- параметры перегенерации аппликатуры: пресет auto/solo/rhythm/bass, шесть
  числовых параметров, «предпочитать открытые»;
- enriched-MIDI и HTML-отчёт после применения плана;
- piano-roll с плеером и выбором тембра предпрослушки;
- удаление сессии.

### Реальные данные для макетов

Файл `Spring_Melody_v3_final.gp`: Spring Melody, 75 BPM, 95 тактов, 4/4,
9 дорожек:

| # | Дорожка | Тип | Роль |
|---|---|---|---|
| 1 | Drums | Shreddage Drums | барабаны |
| 2 | Acoustic Bass | Darkwall | ритм-секция |
| 3–4 | Keyboard (Staff 1/2) | без маппинга | прочее |
| 5–6 | Synth (Staff 1/2) | без маппинга | прочее |
| 7 | Vocals | без маппинга | прочее |
| 8 | Guitar (Solo) | Hydra | соло; 204 ноты с авторскими сдвигами |
| 9 | Guitar (Rhythm) | Hydra | ритм-секция |

Для DAW-чек-листа:
- Hydra: PITCH BEND RANGE = 7;
- Picking Mode C7/C#7 — при `pick_direction`;
- Vel → Tightness — при `palm_mute_motion`;
- Darkwall: PITCH BEND RANGE = 2.

### Что уже решено в первом прототипе (можно оспорить с аргументом)

- **Оживление — у каждой роли своё**, а не один общий выключатель: в
  конвертере оно задаётся по дорожкам, и можно оживить барабаны, оставив
  гитару как в нотах.
- Опции, которым нужно оживление, появляются внутри включённого «Оживить».
  Остальные — отдельным блоком «Без оживления».
- «Точность нот» свёрнута и помечена «по умолчанию / изменено», есть сброс.
- Таблица «по дорожкам»: строки — дорожки, столбцы — 13 опций. «—» —
  недоступно для типа дорожки, подсветка — ручное исключение.
- Результат: чек-лист DAW зависит от выбранных опций, версии переключаются
  чипами.
