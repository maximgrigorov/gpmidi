# UI glossary (English copy, 2026-10-09)

The web UI is in English. Keep new copy consistent with these terms; the left column is
the Russian wording used in plans, AGENTS.md and LESSONS.md, so the two can be matched.

Product name: **GP MIDI Studio**. Tone: short, plain, musician-friendly, sentence case
("Build MIDI", not "Build Midi"). No exclamation marks. Use typographic quotes “ ” and the
middle dot · as in the existing UI. Numbers with units: "128 MB", "9–16 ms".
