Вложенные опции · два уровня
▸ Промпт для модели

Дочерние опции существуют в DOM, только когда родитель включён (серверный шаблон + hidden). Выключение родителя не сбрасывает дочерние — при повторном включении они возвращаются. На сервер дочерние поля уходят только при включённом родителе.
